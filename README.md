# 📌 주요 기능 요약

- 게시글 작성 (POST)
- 게시글 목록 조회 (GET)
- 단일 게시글 상세 조회 (GET)
- 게시글 수정 (PUT)
- 게시글 삭제 (DELETE)
- 조회수 자동 증가 기능
- 게시글 상태(`공개`, `비공개`, `임시`) 관리
---
📦 패키지 설치

```python
pip install -r requirements.txt
```
---
🚀 Flask 서버 실행
```python
python run.py
```
